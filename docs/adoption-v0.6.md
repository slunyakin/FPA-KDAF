# Adopt KDAF v0.6

KDAF v0.6 is ready for public local evaluation and early-adopter inspection. Start with the path
that matches your goal:

| Goal | Start here | Evidence produced |
| --- | --- | --- |
| Prove it works from a fresh clone | [Quickstart](quickstart-v0.6.md) | Passing smoke tests, cited answer, refusal, stored evaluation result |
| Watch the complete workflow | [Public demo](public-demo-v0.6.md) | Project, starter kit, CARP context, evidence packet, answer, evaluation metadata |
| Compare repeatable finance behavior | [FP&A benchmark](fpna-benchmark-v0.6.md) | Seven graded cases covering finance and refusal behavior |
| Review trust and maturity claims | [Release readiness](release-readiness-v0.6.md) | Test status, Docker status, architecture coverage, limitations, roadmap candidates |
| Understand storage and interfaces | [Architecture](architecture-v0.6.md) | Store ownership, service flow, error contract, detailed contract links |
| Map adoption to a team role | [Role-based guide](role-based-consumer-guide.md) | Analyst, finance leader, modeler, engineer, developer, auditor, operator paths |

## Adoption boundary

The public evidence supports local evaluation and framework inspection. It does not claim a
production deployment. Before production adoption, review the limitations and operational controls
in the readiness report and apply organization-specific identity, authorization, retention,
monitoring, backup, recovery, source-quality, and analytical-review requirements.
